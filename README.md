# قوايم MIDO

## صفحة التحكم (لوحة MIDO)

**https://midodorgham.github.io/mido-lists/**

منها بتضيف أفلام وقنوات، وترفع ملفات M3U، وتختار القوايم الأونلاين (القنوات المجانية الرسمية من
[Free-TV](https://github.com/Free-TV/IPTV))، وتشوف القايمة اتحدّثت ولا لسه. أول مرة بس هتطلب منك «مفتاح» من
GitHub، والصفحة بتقولك تعمله إزاي في دقيقة.

## اللينك اللي بتحطه في كل الأجهزة (تطبيق MIDO ← M3U)

```
https://raw.githubusercontent.com/Midodorgham/mido-lists/main/mido.m3u
```

أي تغيير بيوصل لكل الأجهزة خلال حوالي ٥ دقايق، لما التطبيق يتفتح أو تدوس «تحديث».

## الملفات

| الملف | فيه إيه |
|---|---|
| `my-list.m3u` | الأفلام والقنوات اللي بتضيفها من الصفحة |
| `lists/*.m3u` | ملفات M3U اللي بترفعها |
| `sources.txt` | لينكات القوايم الأونلاين (بتتنزل من جديد كل يوم الساعة ٥ الصبح) |
| `mido.m3u` | القايمة النهائية اللي الأجهزة بتقراها. **ماتعدّلهاش بإيدك**: بتتعمل لوحدها |
| `build-info.json` | أعداد القنوات والأفلام اللي الصفحة بتعرضها |
| `build-list.sh` و `.github/workflows/build.yml` | اللي بيجمع كل ده في `mido.m3u` |

لينكات الاشتراكات اللي فيها يوزر وباسورد بتتشال لوحدها: الـ repo عام وأي حد يقدر يشوفه.

حط بس محتوى ليك حق تعرضه.
