# سيرفر MIDO (يوزر وباسورد لكل عميل)

كل عميل بياخد **يوزر وباسورد** بدل اللينك. بتعملهم من «لوحة العملاء»، وتحدد المدة، وتوقف أو تجدد أي حد في ثانية.
السيرفر بيقرا قايمتك نفسها (`mido.m3u`) كل ١٠ دقايق، فأي حاجة تضيفها من «لوحة MIDO» بتوصل للعملاء لوحدها.

## اللي محتاجه
- سيرفر VPS صغير: Ubuntu 24.04، ١ جيجا رام كفاية (حوالي ٥ دولار في الشهر، مثلاً Hetzner أو DigitalOcean أو Contabo).
- السيرفر مابيعديش الفيديو من عليه: بيتأكد من الحساب وبعدين يحوّل الجهاز على لينك القناة الأصلي، فمش محتاج سيرفر كبير.

## التركيب (مرة واحدة)
ادخل على الـ VPS (من صفحة الشركة فيه زرار Console، أو `ssh root@IP`) والزق السطر ده:

```
curl -fsSL https://raw.githubusercontent.com/Midodorgham/mido-lists/main/server/install.sh | sudo bash
```

هيسألك على باسورد للوحة، وفي الآخر يكتبلك:
- **لوحة العملاء:** `http://IP/admin`
- **عنوان السيرفر للعملاء:** `http://IP`

## العميل بيعمل إيه
في تطبيق MIDO يختار **Xtream** ويكتب: السيرفر، اليوزر، الباسورد. ولو برنامج تاني بيطلب M3U، زرار «نسخ البيانات» بيديله لينك M3U خاص بيه.

## أوامر مفيدة على الـ VPS
| عايز | اكتب |
|---|---|
| تشوف شغال ولا لأ | `systemctl status mido-server` |
| تعيد تشغيله | `systemctl restart mido-server` |
| تحدّثه لآخر نسخة | نفس سطر التركيب تاني (العملاء والباسورد بيفضلوا زي ما هم) |
| تغيّر باسورد اللوحة | `nano /etc/mido-server.env` وبعدين `systemctl restart mido-server` |
| نسخة احتياطية من العملاء | `/opt/mido-server/data/customers.json` |

## مهم
- الحسابات بتشتغل بس على المحتوى اللي في قايمتك. حط بس قنوات وأفلام ليك حق تعرضها.
- ملف العملاء فيه باسوردات العملاء، فماترفعهوش على GitHub ولا تبعته لحد.
